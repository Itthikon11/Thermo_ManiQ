# รูปภาพของหน้าเว็บ

เอารูปจริงมาวางทับไฟล์เดิม โดย**ใช้ชื่อไฟล์เดิม** (โค้ด import ตามชื่อนี้):

| ไฟล์ | ใช้ที่ section | รายละเอียดรูป |
|------|----------------|----------------|
| `logo.png`     | Navbar | โลโก้ THERMO MANIQ (หกเหลี่ยม ฟ้าผ่าส้ม) — ✅ ใส่ให้แล้ว |
| `hero-bg.png`  | รูปที่ 1 Hero | ภาพแผงโซล่าเรืองแสงส้มบนพื้นดำ (แนวนอน กว้าง) — ⚠️ ยัง placeholder |
| `house-3d.png` | รูปที่ 2 | บ้าน 3D ติดโซล่า + แบตเตอรี่ (พื้นโปร่ง) — ⚠️ ยัง placeholder |
| `solar-3d.png` | รูปที่ 3 | แผงโซล่า 3D + แบตเตอรี่บนหญ้า (พื้นโปร่ง) — ⚠️ ยัง placeholder |

> ไฟล์ที่ยัง placeholder เป็นรูปจุดเดียวโปร่งใส กันโปรเจกไม่พังเฉยๆ
> วางรูปจริงชื่อเดิมทับได้เลย เว็บจะอัปเดตอัตโนมัติตอน `npm run dev`
